# MTracker

Family clothing measurements: how to measure with a soft tape (with diagrams), a place to record each fitting, and sizes to shop (shirt neck/sleeve, suit chest + length, trousers waist × inseam).

- The page is a single static `index.html` served by GitHub Pages.
- Measurements are stored in the owner's Google Sheet through a Google Apps Script web app (see `API` near the top of the script in `index.html`).
- Access needs the family code, which is set in the Apps Script and is **not** stored in this repo.
